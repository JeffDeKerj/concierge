  the owner was away (-120 dBFS). See Sharp edges. This is the likely cause
  of "Nestor did not respond" this morning, which the first log of the day
  left open.
- **The lid was closed, and a closed lid cuts the Mac's own microphone.** At
  the desk the headset is the only microphone there is.
- **A second copy of the app opens no window** when started beside the
  running one (`open -n --env CONCIERGE_DIR=…`), and the binary aborts when
  started directly from Claude's shell. A web view inside a test works, so
  page behaviour is checked there.
- **A deny rule in `--settings` hides the tool** from the model; it is not
  a refusal. To refuse a call when it is made, use a `PreToolUse` hook that
  exits 2.
