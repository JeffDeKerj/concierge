# 2026-11-24 — first version of the app

Started from an empty folder holding only `.gitignore` and the first generated
page. Branch `app-v1` off the initial commit.

## Landed

- Swift package in the shape of `finance-update-ui`: `Package.swift`,
  `Sources/ClaudeAssistant/`, `Scripts/swift-build-flags.sh` copied as is,
  `Scripts/make_app.sh` adapted (no icon yet), `Scripts/test.sh` and a stub CLI.
- `Paths.swift`: project folder and `claude` lookup, both overridable by
  environment for tests. `BriefingPage.swift`: the page picker.
  `ClaudeRunner.swift`: one headless run with the project as working directory,
  stoppable. `AppModel.swift`: page state, Refresh with a two-second file
  watcher, the follow-up with its fallback. `BriefingWebView.swift`: string-
  injected page, links to the browser. `ContentView.swift`: notice line, error
  line, page, follow-up panel, toolbar with date, Refresh, spinner and timer.
- Ten Swift Testing tests, all passing, run through `Scripts/test.sh`.
- `README.md`, this log, the handoff doc, `stable.md`, `sharp-edges.md`, `tried.md`.

## Checked

- Release build with the sibling flags: clean, one deprecation warning about
  `--build-system native` that the pin itself causes.
- Launch on today's page: screenshot showed the real page, dark, with the date
  in the toolbar, the Refresh button and the follow-up field.
- Refresh against the real CLI: ran, failed at once with "Failed to authenticate:
  OAuth session expired and could not be refreshed", shown in red above the page.
  `claude auth status` confirmed the CLI is logged out. Today's page was
  untouched (compared against a copy).
- Refresh against the stub on a scratch project: the notice "Today's briefing is
  not there yet. Showing Monday 23 November." and the spinner with a timer
  showed while the stub slept, then the rebuilt page replaced it with today's
  date and no notice.
- Follow-up: covered by tests only (the `--continue` call and the fallback
  without it). Not exercised by hand, since the CLI is logged out and typing
  into the field needs Accessibility.
