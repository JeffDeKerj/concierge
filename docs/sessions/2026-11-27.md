# 2026-11-27: a Download French button

The owner tried to add French under System Settings › Keyboard › Dictation
and it never arrived. Found by reading the system log:

- French (France) was already ticked, with Dictation off. Switching
  Dictation on fetched nothing.
- At 08:34 the Mac's download service failed twice with "no Internet
  connection" on `gdmf.apple.com`, though that server answered from a shell.
- At 08:36 and 08:40 it reached Apple, asked for English (UK) only, and got
  "nothing new". French was never in the request.

The Mac's newer speech engine lists French as supported and lets an app
download a language. `SFSpeechRecognizer` follows the dictation files, not
the newer transcriber's: `en-AU` has transcriber files installed and is
still not recognised on the Mac by the old engine.

Built on `french-switch`: `SpeechDownload.swift` and a **Download French**
button in Settings › Voice, shown whichever language is chosen while French
is not on the Mac, with progress, the reason for a failure and a retry. The
spoken hint now points at the button. 78 Swift tests and 10 Python tests
pass; the button was seen in the rebuilt app. It was not pressed: downloads
are the owner's. Whether Nestor can use French after the download is not
known yet.
