# 2026-11-24c — dismiss button, model per operation, scroll position

Two branches off `main`, each merged when done: `dismiss-items`, then
`model-per-operation` (which also carries the scroll fix and a cost correction).

## Landed

- **Dismiss button** (`PageScript.swift`, `DismissStore.swift`). The app adds a
  "×" to every top-level item under Urgent actions, Other conversations, Papers
  to read and Already handled. Pressing it hides the item and appends
  `{key, title, source, section, dismissedAt}` to `briefings/dismissed.json`.
  Each section then shows "n dismissed · Show"; shown items are greyed with a
  "↩" that puts them back. View > Forget Dismissed Items empties the list and
  reloads. Keys: the page's `data-key`, else the Gmail thread id in the item's
  link, else the item's own words (title, or text without tag and time).
- **Skill**: `~/.claude/skills/briefing/SKILL.md` gained a "Dismissed items"
  section (read the file, leave matching items off, bring one back tagged NEW
  only when the source moved after `dismissedAt`) and the `data-key` rule
  (`mail:`, `whatsapp:`, `ci:`, `paper:`, `topic:`). `example.html` carries keys.
- **Model per operation** (`ModelSettings`, `Operation`, `ModelOption`). Agent
  menu: "Model for Refresh" and "Model for Questions", one list per backend,
  saved per backend as `model.<operation>.<backend>`. Claude: Default, Opus,
  Sonnet, Haiku, defaults Opus for Refresh and Sonnet for questions. Antigravity:
  five of `agy models`. Codex: Default only. Every backend takes the model in
  `refreshArguments(model:)` and `askArguments(question:continuing:model:)`.
- **Continued conversations are charged the difference.** `claude -p --continue`
  reports `total_cost_usd` for the whole conversation. `RunReport.sessionID`
  (`session_id`, or agy's `conversation_id`) and `RunLog.Entry.sessionCostUSD`
  keep the running total; `RunLog.append` returns the report with `costUSD`
  reduced to this run's share and the model shows that.
- **Scroll position** (`BriefingWebView`): when the same file reloads (Refresh
  wrote it, or the dismissed list was cleared) the web view reads `scrollY`
  first and scrolls back there after the load; a different day's page and the
  first load start at the top.
- 24 tests. The stub now answers with a `session_id`.
