# 2026-11-24b — headless Refresh for real, cost readout, agent seam

Branch `headless-refresh-cost` off `main` after the version-1 merge.

## Landed

- `.claude/settings.json`: the allow-list for headless runs in this folder
  (read-only Gmail and Calendar tools, WhatsApp, `Write(briefings/**)`, the
  headless Chrome command). The folder was trusted in `~/.claude.json`.
- `AgentBackend.swift`: the seam. `RunReport` (text, error, price, duration,
  turns, tokens, model, refused tools) and the `AgentBackend` protocol.
  `ClaudeBackend`, `AntigravityBackend`, `CodexBackend`. `AgentRunner`
  replaces `ClaudeRunner` and takes a backend. `RunLog` appends every run to
  `briefings/runs.jsonl` and totals today.
- `CostLine` under the page; an Agent menu with a picker and "Reveal Run Log".
- Refresh and the follow-up now use JSON output, show refused tools by name,
  and quote what the generator said when it exits without writing.
- Stub answers in Claude's JSON shape, with a `denied` mode. 19 tests.
