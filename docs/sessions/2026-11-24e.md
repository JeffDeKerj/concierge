# 2026-11-24e — proactive Concierge

Branch `proactive`. The owner asked for proposals 2–7 at once plus a way to
switch them off on a day they want to save tokens.

## Landed

- **Settings window** (Concierge > Settings, ⌘,) writes `briefings/settings.json`.
  "Pause everything today" sets `pausedOn`; one switch per job; models for the
  daytime jobs (Haiku for checks, Sonnet for prep and wrap-up by default).
- **Job runner** `Scripts/tick.py` (stdlib, `/usr/bin/python3 -I`), launchd
  agent `com.concierge.tick` every 15 min (`Scripts/com.concierge.tick.plist`).
  It reads the settings itself, so a switched-off or paused job costs nothing.
  State in `briefings/state/tick.json`, log in `briefings/state/tick.log`.
  Each run goes to `runs.jsonl`, so the app's cost line counts it.
- **Skills** in `~/.claude/skills/`: `concierge-check` (new urgent things since
  the last check), `concierge-prep <event id>` (before an event in
  `briefings/agenda/<day>.json`), `concierge-wrapup` (evening). All write to
  `briefings/updates/<day>.json`; entries with `notify` become a Mac
  notification and an ntfy message to `…:31443/concierge` on spark.
- **Briefing skill**: honours the settings; drafts replies (Gmail drafts on
  the thread, WhatsApp text on the page with a Copy button); tracks open
  items across days in `briefings/open-items.json` ("Open N days", moved up);
  learns from `briefings/dismiss-history.jsonl` (3+ dismissals of one kind
  are left off, said in the footer); writes the agenda file.
- **App**: "Since this morning" panel above the page, re-read every minute;
  "×" on its items; Copy on drafts; every dismissal appended to the history.
- Headless allowlist gained Gmail `create_draft` and `list_drafts`.
